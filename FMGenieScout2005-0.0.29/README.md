# FM Genie Scout 2005 — 0.0.29.1

Primeira base consolidada de jogadores com estabilização de qualidade dos dados.

## Recursos

- identidade por `PersonDatabaseId`;
- contrato profissional e empréstimo;
- clube proprietário e clube ativo;
- salário semanal interno;
- início e término do contrato;
- contratos de formação com término `N/D`;
- agente livre confirmado sem clube;
- flags de qualidade e validações conhecidas.

Consulte `README-0.0.29.1.txt` para detalhes.
